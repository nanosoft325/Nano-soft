# Безопасное размещение сайта

## Требования к хостингу

- Размещайте сайт только по HTTPS. Обработчик использует защищенную сессию и отклоняет отправки без HTTPS-origin.
- Нужны PHP 7.4 или новее и расширения `curl`, `fileinfo`, `mbstring`, `openssl`.
- Включите PHP-сессии, `mail()` или SMTP-релей, если нужны почтовые копии заявок.
- Для Apache нужен `mod_headers`; файл `.htaccess` включает защитные заголовки, CSP, HSTS и отключает просмотр содержимого каталогов. Если хостинг на Nginx, перенесите эти правила в конфигурацию Nginx: `.htaccess` там не действует.

## Настройки PHP

В панели хостинга или `php.ini` установите лимиты с учетом формы:

```ini
file_uploads = On
upload_max_filesize = 10M
post_max_size = 11M
max_file_uploads = 1
max_input_time = 60
max_execution_time = 45
memory_limit = 64M
display_errors = Off
log_errors = On
expose_php = Off
```

Путь хранения сессий PHP и системная временная папка должны быть доступны PHP на запись и недоступны из веба. При заполненном `post_max_size` PHP может отбросить тело запроса до запуска обработчика, поэтому эти значения нужно задать на стороне хостинга.

## Секреты и адрес сайта

Добавьте в переменные окружения PHP на хостинге:

- `TELEGRAM_BOT_TOKEN` — токен бота Telegram;
- `TELEGRAM_CHAT_ID` — ID чата или канала для заявок;
- `CONTACT_NOTIFY_EMAIL` — почта для копий заявок (необязательно; по умолчанию используется адрес сайта);
- `NANOSOFT_SITE_ORIGIN` — точный origin сайта, например `https://nanosoft.team` без завершающего `/`.

Не публикуйте токен бота в HTML, JavaScript, архивах проекта, репозитории или переписке. Если токен уже попадал в публичный доступ, отзовите его через BotFather и создайте новый. Не добавляйте рабочие значения в этот проект.

## Что защищает обработчик

Обработчик проверяет same-origin запросы и CSRF-токен сессии, согласие пользователя, тип и сигнатуру вложений, ограничивает вложения до PDF/DOCX/ZIP по 10 МБ и ограничивает отправку с одного IP пятью заявками в час. Данные заявок не сохраняются в файлы сайта. Ограничение частоты хранится в системной временной папке; если сайт обслуживается несколькими серверами, настройте также общее ограничение частоты на WAF/CDN или балансировщике.

Файлы не сканируются антивирусом: они пересылаются в Telegram и на почту. Для конфиденциальных документов и публичных форм добавьте антивирусную проверку на сервере либо отключите вложения. Не доверяйте заголовку `X-Forwarded-For`, если хостинг сам не настроен передавать его от доверенного прокси.

## Проверки после размещения

Проверьте у хостинга, что сайт открывается только по HTTPS, `send.php?csrf=1` отвечает JSON без кеширования, форма успешно доставляет заявки, лимит размера запроса согласован с PHP и WAF, а ответ сайта содержит заголовки из `.htaccess` (либо их эквиваленты в Nginx). Настройки хостинга нельзя подтвердить по одним файлам проекта.
